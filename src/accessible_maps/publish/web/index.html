How to verify cryptographic package signatures & checksums

All distributed dataset archives include cryptographic SHA-256 checksums and optional Ed25519 digital signatures to guarantee data authenticity and integrity.

To verify the SHA-256 checksum on Linux / macOS:

# Verify dataset archive integrity
sha256sum -c checksums.txt

To decompress high-performance Zstandard (.zst) datasets:

# Unpack .gpkg.zst into standard .gpkg
zstd -d <region>-<version>.gpkg.zst
